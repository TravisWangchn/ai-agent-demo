AI Agent 教学演示

从一个 Issue，看懂 AI Agent 如何工作

这个项目把一次真实的 Agent 工作拆成五个阶段：触发、评估、决策、执行、交付。读页面、跑演示、看规则，就能理解它如何判断一个请求该不该做、要做到什么程度。

运行交互演示 阅读工作流程
5 个清晰阶段
4 类教学任务
0 运行时依赖

Agent Workflow

  1. 01 触发 · 收到 Issue 或消息
  2. 02 评估 · 收集必要上下文
  3. 03 决策 · 匹配规则并判断
  4. 04 执行 · 分支、代码、测试
  5. 05 交付 · PR、证据、复核

本地运行与测试

项目保持零依赖、零构建。页面脚本使用原生 ES modules，请通过静态服务器访问。

先看看演示 
# 启动本地静态服务器（任选一种）
python -m http.server 8000
npx serve .

# 运行单元测试
npm test

现代浏览器会阻止 file:// 下加载 ES module，因此导航菜单、规则表和交互演示需要静态服务器；直接双击 index.html 仍可查看 HTML 与样式。
